# Validation

Windows x64, Quantimation v0.2.0, 28 October 2026.

- 30 automated tests cover production validation, round-trip, scene/shot boundaries, interpolation, resource bounds, named joints, variant targets, deterministic standards, five cast rigs and reusable poses, SRT timing, procedural sound, provider contracts, cancellation, custom HTTP voice fields and PCM speech synthesis.
- MCP integration tests negotiate a real stdio session and discover 21 tools. Loopback checks cover bearer authentication, rejected browser origins, Unicode and multiple-app discovery ownership.
- The Windows packaged application launches with context isolation and renderer sandbox enabled. Its navigation, central preview, timeline, assets and standards picker were visually inspected. A live MCP client read all 18 standards, fetched a family rig, inserted a palette-customized moon and undid the edit successfully.
- The new dragon project validates at 30 seconds, three scenes, eleven shots, eleven assets and six dialogue lines. Five additional voice auditions are bundled with the Quantumania cast. Speech was synthesized locally with Kokoro q8 on CPU.
- Family review rendered neutral, smug, shocked and angry poses for every character. Inspection led to silhouette/proportion changes and safer pose-sheet spacing. Mouths use distinct replacement drawings, not only scaled ellipses.
- Technical QA is separate from creative approval. Render statistics measure preview drawing intervals, not encoded frame count. Actual encoded cuts still need viewing and listening; no model automatically certifies television quality.

Model integration tests use deterministic HTTP fixtures, not a live generative LLM. Vision-model review and automatic visual repairs are proposed architecture, not connected functionality.

macOS/Linux runtime behavior, distribution installation, system voices and live cloud providers require target-environment testing. GitHub Actions is configured to build each OS; consult its actual result. Packages are unsigned. Full IK, authored back/profile turnarounds for the family, phoneme alignment, cloth simulation and production voice direction remain further work.
